# 就労継続支援B型 工賃実績報告 自動集計サンプル

就労継続支援B型事業所における利用実績・工賃支給実績をもとに、不備チェック・集計・行政指定Excelへの転記を行うPythonサンプルです。

実際の業務委託案件の募集要件をもとに、案件内容を理解したうえで実装可能であることを示すための営業サンプルとして作成しています。

## このサンプルで実装していること

### 1. Excelデータの取込

以下のサンプルデータをPython / pandasで読み込みます。

- 利用実績
- 工賃支給実績
- 事業所情報

使用しているデータはすべて架空のものです。実在する利用者の個人情報は含まれていません。

### 2. データの不備・要確認項目の検出

以下を自動的に検出します。

- 同一利用者・対象月の工賃実績の重複
- 利用実績があるにもかかわらず工賃実績が存在しないケース
- 対象月と実際の支給月が異なるケース

対象月と支給月が異なる場合については、遡及支給等の正常なケースも考えられるため、一律にエラーとはせず「要確認」として扱っています。

### 3. 月別集計

正常データをもとに、月別の工賃実績を集計します。

また、集計結果だけでなく、

**報告値 → 集計明細 → 元データ**

まで確認できるよう、Excel内に「月別集計」「集計明細」「元データ」の各シートを出力します。

### 4. 行政指定Excelへの自動転記

公開されている名古屋市の工賃実績報告Excelをサンプル様式として使用し、公式様式をコピーしたうえで集計値を所定のセルへ転記します。

現在のサンプルでは以下を転記しています。

- 定員
- 年間工賃支払総額
- 年間利用者延べ人数
- 年間開所日数
- 年間開所月数

平均利用者数・工賃平均額については、行政Excelにあらかじめ設定されている計算式を維持して利用します。

## 処理イメージ

```text
利用実績.xlsx ──┐
工賃実績.xlsx ──┼─→ Python
事業所情報.xlsx ─┘      │
                         ├─ 不備・要確認項目の検出
                         ├─ 月別・年間集計
                         ├─ 集計明細・元データの出力
                         │
                         ↓
                  行政指定Excel
                         ↓
                  提出用Excel
```

## 出力ファイル

```text
output/
├── エラー一覧.xlsx
├── 月別集計.xlsx
└── 提出用_工賃実績報告.xlsx
```

`エラー一覧.xlsx` では、問題の内容だけでなく、担当者が次に確認すべき内容も表示します。

## 本番開発との違い

本リポジトリは営業用サンプルであり、完成版システムではありません。

実案件では、利用中ソフト・実際の出力データ・対象自治体・報告年度・記載要領・過年度報告書等を確認したうえで、正式なデータ取込方法と計算条件を仕様化する必要があります。

特に以下については、本サンプルでは簡略化または未実装です。

- 複数事業所・複数年度の管理
- 正式な年間開所日数の取得方法
- 自治体記載要領に基づく正式な計算条件
- 月途中の利用開始・終了
- 遡及支給・訂正等の特殊ケース
- 過年度報告書との照合
- 年度・行政様式変更への設定ベースでの対応
- 実データを用いた検証・テスト

年間開所日数等については、サンプルでは事業所情報の設定値を使用しています。本番では、発注者が利用しているソフトや出力データを確認し、取得・算出方法を確定する想定です。

不明な業務ルールを推測して固定実装するのではなく、実データ・自治体資料・過年度報告書を確認したうえで仕様を確定することを前提としています。
